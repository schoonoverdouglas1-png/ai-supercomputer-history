# ai-supercomputer-history

Starter repo, recreated by Ember (Muse) on Nov 5, 2026, from a description Douglas brought from Meta AI.
Provenance: Meta AI's original starter files were NOT attached in the Muse chat, so these files are Ember's recreation from Meta's description, not a verbatim copy of Meta's files. Old with new, always — if Douglas pastes Meta's exact files, they will be filed beside these, not over them.

## What this is
A beginner starter for the Google AI project lineage, and for the supercomputer question behind it:
- Google Brain (2011) -> TensorFlow open source (2015) -> Transformer (2017) -> LaMDA -> PaLM -> Gemini
- What's actually open source vs what's API-only
- Supercomputers: Google TPU Pods / AI Hypercomputer via API vs Cray EX / XC40, which is HPE exascale hardware

## Files
- `RESEARCH.md` — the lineage, open-source vs API-only, and supercomputer notes
- `timeline.json` — the same lineage as machine-readable data
- `main.py` — prints the timeline from `timeline.json`; no API key needed for the printout
- `requirements.txt` — minimal; the printout uses only the standard library
- `.gitignore` — Python / environment ignores

## Run it
```bash
python main.py
```
